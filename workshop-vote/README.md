# 본부 워크샵 일정 투표

`index.html` — 선호 요일(월~금)과 2026년 11~12월 선호 날짜를 중복 선택으로 받는 투표 페이지입니다.
응답은 Google 스프레드시트에 저장되고, 페이지 하단에 집계(응답 인원, 요일별 인원, 많이 고른 날짜 TOP 5)가 표시됩니다.

## 응답 저장소 연결 (처음 한 번)

1. Google 스프레드시트를 새로 만듭니다. (예: `본부 워크샵 일정 투표 응답`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형: **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 권한 승인 후 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. `index.html` 위쪽의 `SCRIPT_URL: ""` 따옴표 안에 붙여 넣고 커밋합니다.

응답은 스프레드시트의 `응답` 시트에 한 사람당 한 줄로 쌓이며, 같은 이름으로 다시 저장하면 그 줄이 바뀝니다.

## 페이지 공개 (GitHub Pages)

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정하면
`https://pppphanul-blip.github.io/job/workshop-vote/` 주소로 열 수 있습니다.

## 참고

- 이 저장소는 공개 저장소이므로, 페이지 주소와 웹 앱 URL을 아는 사람은 누구나 응답하거나 집계(응답자 이름 포함)를 볼 수 있습니다.
- 로그인 없이 이름으로 응답자를 구분하므로, 동명이인은 이름 뒤에 팀명을 붙여 달라고 안내해 주세요.
- 주말, 지난 날짜, 12월 25일(성탄절)은 선택할 수 없습니다.
